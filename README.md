# EV Range Estimator

A React application built with Vite for estimating electric vehicle range based on various factors.

## Getting Started

### Prerequisites
- Node.js (version 18 or higher)
- npm

### Installation
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Development
Run the development server:
```bash
npm run dev
```

### Build
Build for production:
```bash
npm run build
```

### Preview
Preview the production build:
```bash
npm run preview
```

## Features
- Estimate EV range based on battery level, driving conditions, temperature, and speed
- Support for multiple EV models
- Real-time calculations with optimistic, pessimistic, and estimated ranges
